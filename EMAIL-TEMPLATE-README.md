## 🚀 How to Use This Template

### Option 1: Email Marketing Platforms (Recommended)

#### **Mailchimp**
1. Log in to Mailchimp
2. Create a new campaign → Email
3. Select "Code your own" template
4. Paste the entire HTML code from `meta-ads-email-template.html`
5. Preview and test across devices
6. Send!

#### **SendGrid**
1. Go to Marketing → Email Templates
2. Click "Create Template"
3. Choose "Blank Template" → Code Editor
4. Paste the HTML code
5. Save and use in campaigns

#### **Brevo (formerly Sendinblue)**
1. Campaigns → Email Templates
2. Create a new template → Rich Text Editor
3. Switch to "Edit HTML code"
4. Paste the template code
5. Save and apply to campaigns

#### **HubSpot**
1. Marketing → Email → Templates
2. Create template → Drag and drop → Custom HTML
3. Paste the code
4. Save template

Gmail and Outlook strip most CSS and may break the design. For best results, use an email marketing platform.

## 🛠️ Troubleshooting

### Images Not Loading?
- Ensure image URLs are publicly accessible (not localhost)
- Use HTTPS links (not HTTP)
- Test with https://www.mail-tester.com

### Layout Broken in Outlook?
- Outlook uses Microsoft Word's rendering engine (old tech)
- The template is table-based for Outlook compatibility
- If issues persist, test with Litmus or Email on Acid

### Email Going to Spam?
- Use a reputable email service provider (Mailchimp, SendGrid, etc.)
- Authenticate your domain (SPF, DKIM, DMARC records)
- Avoid spam trigger words ("FREE!!!", "ACT NOW!!!")
- Test spam score: https://www.mail-tester.com

### Links Not Clickable?
- Ensure all `href` attributes have full URLs starting with `https://`
- Test links in preview mode before sending
